# 右值引用、移动语义、完美转发

## 核心概念（面试极简背诵版）

### 1. 左值 & 右值（基础）

- **左值**：有名字、可取地址、生命周期持久（变量、对象）
- **右值**：无名字、临时对象、即将销毁（字面量、函数返回值、临时对象）
- **将亡值 (xvalue)**：被`std::move`标记的左值，属于右值

### 2. 右值引用 `&&`

- 专门**绑定右值**的引用，不绑定普通左值
- 作用：延长临时对象生命周期，为**移动语义**提供语法基础

cpp

运行

```
int&& a = 10;       // ✅ 绑定右值
int b; int&& c = b; // ❌ 不能绑定左值
```

### 3. 移动语义（核心价值）

- 拷贝语义：**复制资源**（深拷贝），耗时、产生冗余
- 移动语义：**窃取资源所有权**，原对象置空，**无拷贝、效率极高**
- 适用：动态数组、智能指针、文件句柄等带堆资源的对象

### 4. `std::move()`

- **本质**：静态类型转换 `static_cast<T&&>(val)`
- **作用**：把左值**强制转为右值**，标记为 “可被移动”
- **误区**：`move`本身**不移动任何数据**，只是类型转换

### 5. 完美转发 `std::forward()`

- 配合 ** 万能引用（`T&&`/`auto&&`）** 使用
- **作用**：完美保留参数的**左值 / 右值属性**，转发时不丢失类型信息
- 解决问题：转发右值时被退化为左值，导致调用拷贝而非移动

### 6. 万能引用（模板`T&&`）

- 不是普通右值引用，能**接收左值也能接收右值**
- 发生**引用折叠**：
    
    - `T& &&` → `T&`
    - `T&& &&` → `T&&`

## 高频面试题（直接背答案）

### 1. 左值引用`&`和右值引用`&&`的区别？

- 左值引用绑定左值，不能绑定临时右值
- 右值引用绑定右值，可延长临时对象生命周期
- 右值引用用于实现移动语义，左值引用用于常规传参

### 2. 移动构造 / 移动赋值函数的作用？

- 接收右值引用参数，**窃取临时对象资源**
- 避免深拷贝，大幅提升容器、大对象的传参 / 返回效率

### 3. `std::move`做了什么？会不会导致内存安全问题？

- 仅将左值转为右值，无实际内存操作
- 原对象被移动后处于**有效但未定义状态**，不能再读写，否则未定义行为

### 4. 什么是完美转发？为什么需要`forward`？

- 完美转发：函数转发参数时，**完整保留参数的左 / 右值属性**
- 直接转发万能引用参数会退化为左值，`forward`还原原始值类别，保证调用移动语义

### 5. 右值引用、万能引用怎么区分？

- 右值引用：类型确定（`int&&`、`string&&`），只绑右值
- 万能引用：模板`T&&`/`auto&&`，可绑左值也可绑右值，发生引用折叠

### 6. 移动语义和拷贝语义的核心区别？

- 拷贝：复制资源，原对象不变，效率低
- 移动：转移资源，原对象置空，效率接近 O (1)

### 7. 临时对象为什么能用右值引用绑定？

- 临时对象是右值，右值引用专门绑定右值，可延长其生命周期，避免临时对象立即销毁

## 一句话终极总结

- **右值引用**：绑定临时对象，是移动语义的语法基础
- **move**：左值转右值，标记可移动
- **移动语义**：偷资源不拷贝，提效率
- **forward**：完美保留参数值类别，实现完美转发
