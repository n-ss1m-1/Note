## 一、STL 核心组成（一句话）

容器（数据结构）+ 迭代器（遍历指针）+ 算法（通用操作）+ 适配器 + 分配器

---

## 二、容器分类 + **底层实现**（面试必考）

### 1. 序列式容器（线性存储）

1. **vector**：**动态数组**，连续内存
2. **list**：**双向链表**，非连续内存
3. **deque**：**双端队列**，分段连续数组
4. forward_list：单向链表
5. array：静态数组

### 2. 关联式容器（**红黑树**，有序）

1. **map**：key-value，key 唯一
2. **set**：单值，元素唯一、自动排序
3. multimap：key 可重复
4. multiset：元素可重复

### 3. 无序关联容器（**哈希表**，无序）

1. **unordered_map**：平均查找 O (1)
2. **unordered_set**：平均查找 O (1)

### 4. 容器适配器（封装底层容器）

1. stack：栈，默认底层 `deque`
2. queue：队列，默认底层 `deque`
3. priority_queue：优先队列，默认底层 `vector`（堆实现）

---

## 三、**核心容器对比**（高频必问）

### 1. vector vs list

表格

|特性|vector|list|
|:--|:--|:--|
|底层|连续动态数组|双向链表|
|访问|随机访问 O (1)|不支持随机访问|
|插入删除|尾端 O (1)，中间 O (n)|任意位置 O (1)|
|内存|连续，CPU 缓存友好|分散，内存开销大|
|迭代器失效|易失效|仅删除节点失效|

### 2. map vs unordered_map

表格

|特性|map|unordered_map|
|:--|:--|:--|
|底层|红黑树|哈希表|
|有序性|自动有序|无序|
|查找效率|O(log n)|平均 O (1)，最坏 O (n)|
|稳定性|高|低（哈希冲突）|

### 3. deque 特点

双端高效（头尾插删 O (1)），支持随机访问，结合 vector 和 list 优点。

---

## 四、**vector 扩容机制**（面试必问）

1. 空间不足时**自动扩容**
2. GCC 默认 **1.5 倍**，MSVC 默认 2 倍
3. 扩容流程：开辟新内存 → 拷贝元素 → 释放旧内存
4. `reserve(n)`：**预留空间**，不初始化，不改变 size
5. `resize(n)`：**改变大小**，初始化新元素

---

## 五、**迭代器失效**（重中之重）

1. **vector**：扩容、中间插入 / 删除 → 全部失效
2. **list**：仅**被删除节点**的迭代器失效，其余正常
3. **map/set**：仅被删除节点迭代器失效
4. **unordered_map**：扩容、删除节点 → 失效

---

## 六、**emplace_back vs push_back**（高频）

- `push_back`：先构造对象 → 再**拷贝 / 移动**到容器
- `emplace_back`：**原地构造**对象，无拷贝 / 移动，效率更高

---

## 七、红黑树特性（map/set 底层）

保证平衡，查找 / 插入 / 删除稳定 O (log n)

1. 节点非红即黑
2. 根节点黑色
3. 叶子节点（空）黑色
4. 红节点子节点必为黑
5. 任意节点到叶子，黑节点数量相同

---

## 八、哈希表特性（unordered 底层）

1. 结构：**数组 + 链表 / 红黑树**
2. 冲突解决：**链地址法**
3. 负载因子超标 → 自动扩容重排

---

## 九、常用算法（常考）

1. `sort`：快速排序（混合），**不能排 list**
2. `list::sort`：链表专用排序
3. `find`、`reverse`、`for_each`、`swap`

---

## 十、STL 线程安全

- **默认线程不安全**
- 仅**读操作**安全，写 / 修改必须加锁

---

# 一句话终极背诵

**vector 数组连续访问快，list 链表插删快；map 红黑树有序 O (logn)，unordered_map 哈希表无序 O (1)；vector 扩容 1.5 倍，emplace 原地构造更高效；迭代器失效看容器，STL 写操作不安全。**
