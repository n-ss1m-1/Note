- **指针和内存管理**：这是 C++ 的核心，悬空指针、野指针、malloc/new 的区别、内存对齐，面试几乎必问。
- **虚函数和多态**：虚函数表的结构、纯虚函数、为什么析构函数要写成虚函数，这些是面向对象部分的重点。
- **STL 容器**：各种容器的底层实现、迭代器失效的场景，`map` 和 `unordered_map` 的区别，别只会用，要知道原理。
- **智能指针**：`shared_ptr`、`unique_ptr`、`weak_ptr` 的使用和循环引用问题，现在几乎是标配考点。
- **C++11 新特性**：右值引用、移动语义、lambda 表达式、`auto` 推导，这些在大厂面试里问得越来越多。

如果你是刚开始准备，建议先把 **C++ 基础**和**面向对象**的部分搞透，再去看 **STL** 和**新特性**。遇到不理解的地方多结合代码去看，光靠背是很难真正掌握的。

# 四、C++ 类相关（核心：封装、继承、多态底层）

## 知识点结构

1. **类的默认函数（6 大默认函数）**
2. **虚函数 / 纯虚函数（概念、区别、用途）**
3. **虚函数表 vtable + vptr（多态底层）**
4. **继承下的虚表结构（单继承 / 多继承）**
5. **类大小与内存布局（空类、虚函数类、普通类）**
6. **class 与 struct 区别**

## 高频总结

- **类默认函数**：无参构造、析构、拷贝构造、拷贝赋值；C++11 新增移动构造、移动赋值。
    
    写任意构造 → 不再生成无参构造。
- **虚函数**：`virtual` 修饰，有实现，用于多态。
- **纯虚函数**：`virtual f()=0;` 无实现，使类成为**抽象类**，不能实例化，必须被子类重写。
- **虚函数机制**：每个类一张 vtable，每个对象一个 vptr 指向 vtable，运行时查表调用。
- **单继承虚表**：一张表，重写则替换地址。
- **多继承虚表**：多个 vptr，对应多个基类虚表。
- **空类大小**：1 字节（占位）。
- **含虚函数类**：至少一个指针大小（8 字节 / 64 位）。
- **class /struct 仅含 int**：大小一样，都是 `sizeof(int)`，唯一区别是默认访问权限（private/public）。

# 五、C++ 语言特性（现代 C++ 核心：右值、移动、模板）

## 知识点结构

1. 左值 / 右值；左值引用 / 右值引用
2. 移动语义 & 完美转发
3. `std::move` 原理
4. 结构体比较与 `memcmp` 陷阱
5. 模板（函数模板 / 类模板）

## 高频总结

- **左值**：有名字、可取址；**右值**：临时、将亡值。
- **左值引用**：`T&`，绑定左值；**右值引用**：`T&&`，绑定右值，实现移动。
- **移动语义**：偷取临时对象资源，避免深拷贝，提高效率。
- **std::move**：本质是**类型强转**，把左值转成右值引用，不移动任何数据。
- **结构体比较**：不能直接用 `memcmp`，因为有**内存对齐填充字节**，值随机。
- **模板**：编译期多态，实现代码复用。
    
    - 函数模板：推导出类型。
    - 类模板：必须显式指定类型。

# 六、C++ STL（容器、迭代器、算法）

## 知识点结构

1. 常用容器底层（vector、list、map、unordered_map、deque、priority_queue）
2. 插入删除与迭代器失效
3. 线程安全
4. sort 底层实现

## 高频总结

- `push_back` 拷贝 / 移动对象；`emplace_back` **直接原地构造**，更少拷贝。
- **map 底层红黑树**，有序；**unordered_map 底层哈希表**，无序更快。
- **STL 容器都不是线程安全**，读安全、读写必须加锁。
- **遍历过程中插入 / 删除可能导致迭代器失效**，尤其 vector。
- **迭代器删除**：用 `erase(it++)` 或接收返回值。
- **迭代器失效典型场景**：vector 扩容、插入、删除；unordered_map 重哈希。
- `priority_queue` 底层**堆（heap）**，默认大顶堆。
- `deque` 底层是**分段数组 + 中控数组**，双端高效。
- `std::sort`：内省排序（快排 + 插排 + 堆排）。

# 七、智能指针（现代 C++ 内存管理核心）

## 知识点结构

1. 四种智能指针作用
2. `shared_ptr` 引用计数
3. `weak_ptr` 解决循环引用
4. `unique_ptr` 独占所有权
5. 常见问题与泄漏

## 高频总结

- **智能指针**：封装裸指针，自动释放，避免泄漏。
- `shared_ptr`：共享所有权，**引用计数**，为 0 时释放。
- `weak_ptr`：不增加计数，**解决 shared_ptr 循环引用导致泄漏**。
- `unique_ptr`：独占，不能拷贝，只能**移动（std::move）**。
- 智能指针也会泄漏：**循环引用**、野指针、重复释放。
- 问题解决：用 `weak_ptr` 打断循环、避免裸指针混用。

# 八、C++ 内存管理（面试超级重灾区）

## 知识点结构

1. 虚拟内存、分页、地址空间
2. 程序内存分区
3. 内存对齐
4. 堆 / 栈区别
5. new/malloc/delete/free 原理与区别
6. 函数调用栈、动态库装载

## 高频总结

- **虚拟内存**：逻辑地址空间，隔离进程，扩大地址空间。
- **用户态地址空间**：代码段、数据段、bss、堆、栈、共享库。
- **内存分区**：栈、堆、全局 / 静态、常量、代码。
- **内存对齐**：按平台最大基本类型对齐，提高访问效率，避免 CPU 异常。
- **函数调用压栈**：参数、返回地址、栈基址 ebp、局部变量。
- **栈**：自动分配释放，速度快，空间小；**堆**：手动管理，空间大，易碎片。
- `new`：堆上分配，调用构造函数；失败抛异常。
- `malloc`：C 函数，纯分配，不初始化；失败返回 NULL。
- `delete` 调用析构 + 释放；`delete[]` 释放数组。
- `malloc` 底层：小块用 `brk`，大块用 `mmap`。
