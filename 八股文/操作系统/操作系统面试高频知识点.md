## 一、进程与线程（最高频）

### 文档原题

1. 进程和线程的区别？使用线程的心得？
2. 协程与普通线程有什么区别？
3. 堆内存和栈内存有什么区别？局部变量放在堆还是栈？
4. 死锁怎么产生的？怎么避免死锁？如何排查死锁？

### 高频核心知识点

1. **进程 vs 线程**
    
    - 进程：资源分配单位，有独立地址空间，切换开销大
    - 线程：调度执行单位，共享进程资源，切换开销小
    - 通信方式、上下文切换、数据共享差异
    
2. **协程（用户态线程）**
    
    - 完全用户态实现，无内核切换
    - 轻量级、高并发、同步写法写异步
    
3. **死锁四大条件 + 解决 / 避免**
    
    - 互斥、请求保持、不可剥夺、循环等待
    - 避免：破坏任一条件、按序加锁、超时机制
    - 排查：jstack/pstack、日志、锁监控
    
4. **进程通信方式（IPC）**
    
    - 管道、命名管道、消息队列、共享内存、信号量、Socket
    

### 高频扩展面试题

- 什么是僵尸进程 / 孤儿进程？怎么产生？
- 线程池的核心参数与原理？
- 协程为什么比线程轻量？

## 二、内存管理（极高频）

### 文档原题

1. 虚拟内存，内存布局大概是什么样子？
2. 怎么申请堆空间？malloc 是系统调用么？
3. 栈空间地址增长顺序（从低到高还是高到低）？
4. 衡量内存占用有哪些内存部分？清理内存操作哪些区域？
5. 文件拷贝涉及哪些系统调用？多少次拷贝？

### 高频核心知识点

1. **虚拟内存**
    
    - 作用：隔离、扩大地址空间、内存共享、缺页中断
    - 布局：代码段、数据段、BSS、堆、栈、内核区
    
2. **栈 vs 堆**
    
    - 栈：自动分配释放、连续、高地址往低地址增长
    - 堆：手动管理、不连续、低地址往高地址
    
3. **malloc/free**
    
    - malloc 不是系统调用，是 C 库函数，底层调用 brk/mmap
    - 内存碎片、伙伴系统、slab 分配器
    
4. **零拷贝**
    
    - 减少用户态 <-> 内核态拷贝次数
    - mmap、sendfile、DMA
    
5. **Page Cache**
    
    - 页缓存作用、预读、回写、脏页

- 为什么会发生栈溢出？

# 操作系统核心知识点划分 + 面试高频考点汇总

操作系统是后端 / 嵌入式 / 系统岗面试的核心考点，以下按模块梳理知识点，并结合面试高频考点和经典真题，提炼核心考察方向。

## 一、核心模块知识点划分

### 模块 1：进程与线程（面试最高频）

#### 核心知识点

1. 进程基础：定义、特征（动态性 / 并发性 / 独立性 / 异步性）、状态（就绪 / 运行 / 阻塞 / 挂起）、PCB（进程控制块）组成；
2. 进程 vs 线程：核心区别（进程 = 资源分配单位，线程 = CPU 调度单位）、资源开销、并发性、调度切换成本；
3. 线程类型：用户级线程、内核级线程、轻量级进程（LWP）；
4. 进程调度算法：
    
    - 批处理：FCFS、SJF、SRTF、HRRN；
    - 分时：RR（时间片轮转）；
    - 实时：EDF、RMS；
    
5. 进程间通信（IPC）：匿名管道 / 命名管道、消息队列、共享内存、信号量、信号、Socket；
6. 同步与互斥：临界区 / 临界资源、同步 vs 互斥、实现方式（信号量 / 管程 / 互斥锁 / 自旋锁 / 条件变量）、经典同步问题（生产者 - 消费者 / 读者 - 写者 / 哲学家进餐）。

#### 面试高频考点

- 进程与线程的核心区别（必考）；
- 进程调度算法的优缺点 + 适用场景；
- IPC 方式对比（尤其是共享内存 vs 消息队列）；
- 生产者 - 消费者问题的信号量实现（需手写伪代码）；
- 自旋锁 vs 互斥锁的适用场景。

#### 经典面试题

1. 详细说明进程和线程的区别与联系，以及使用线程的优势；
2. 时间片轮转（RR）调度算法中，时间片大小如何影响系统性能？
3. 匿名管道和命名管道的区别？为什么匿名管道仅支持父子进程通信？
4. 用信号量实现生产者 - 消费者问题时，如何避免死锁和饥饿？

### 模块 2：内存管理（次高频）

#### 核心知识点

1. 内存管理目标：空间利用率、多道并发、地址保护、地址独立；
2. 分配方式：
    
    - 连续分配：单一连续 / 固定分区 / 动态分区（首次 / 最佳 / 最坏 / 下次适应）；
    - 非连续分配：分页（页表 / TLB）、分段、段页式；
    
3. 虚拟内存：局部性原理（时间 / 空间局部性）、按需调页、多级页表 / 反置页表；
4. 页面置换算法：OPT（最优）、FIFO（Belady 异常）、LRU、CLOCK、LFU；
5. 内存碎片：内部碎片（分页 / 固定分区）、外部碎片（动态分区 / 分段）；
6. 抖动（Thrashing）：原因（缺页率过高）、解决（工作集模型）。

#### 面试高频考点

- 虚拟内存的实现原理（局部性原理是核心）；
- 页面置换算法（LRU/FIFO/CLOCK 的对比、Belady 异常）；
- 分页 vs 分段的区别、段页式的优势；
- TLB（快表）的作用与工作原理；
- 内存抖动的原因与解决。

#### 经典面试题

1. 虚拟内存的核心原理是什么？局部性原理如何支撑虚拟内存实现？
2. 为什么 FIFO 置换算法会出现 Belady 异常，而 LRU 不会？
3. 快表（TLB）如何提升地址转换效率？TLB 失效时的处理流程？
4. 分页和分段的核心区别？分别解决了什么问题？

### 模块 3：文件系统与 I/O 管理

#### 核心知识点

1. 文件基础：定义、属性、类型（普通 / 目录 / 设备 / 管道文件）；
2. 文件结构：
    
    - 逻辑结构：流式文件、记录式文件；
    - 物理结构：连续分配、链接分配、索引分配（如 Unix inode）；
    
3. 目录结构：单级 / 两级 / 树形 / 图状目录；
4. 磁盘调度算法：FCFS、SSTF、SCAN（电梯算法）、C-SCAN、LOOK；
5. I/O 管理：
    
    - 设备分类：块设备 / 字符设备；
    - I/O 控制方式：程序直接控制、中断驱动、DMA、通道；
    - 缓冲技术：单缓冲 / 双缓冲 / 缓冲池；
    - 设备独立性（逻辑设备→物理设备）。
    

#### 面试高频考点

- Unix/Linux inode 的结构与作用；
- 磁盘调度算法（SCAN 电梯算法的优势）；
- DMA 与中断驱动的区别；
- 缓冲技术的作用；
- 设备独立性的实现原理。

#### 经典面试题

1. 什么是 inode？包含哪些信息？为什么删除文件本质是删除 inode 链接？
2. 电梯算法（SCAN）相比 SSTF 解决了什么问题（如饥饿）？
3. DMA 方式如何减少 CPU 的 I/O 开销？与通道方式的区别？
4. 缓冲池的设计思路？为什么比单 / 双缓冲更高效？

### 模块 4：死锁（高频）

#### 核心知识点

1. 死锁定义：四个必要条件（互斥、请求与保持、不剥夺、循环等待）；
2. 死锁处理策略：
    
    - 预防：破坏任一必要条件（静态分配 / 剥夺资源 / 有序资源分配）；
    - 避免：银行家算法（安全状态 / 安全序列）；
    - 检测：资源分配图化简；
    - 解除：剥夺资源 / 撤销进程；
    
3. 死锁 vs 饥饿 vs 活锁。

#### 面试高频考点

- 死锁的四个必要条件（必考）；
- 死锁处理策略（预防 / 避免 / 检测 / 解除的对比）；
- 银行家算法的核心逻辑；
- 死锁、饥饿、活锁的区别。

#### 经典面试题

1. 死锁的四个必要条件是什么？如何破坏 “请求与保持” 条件？
2. 银行家算法如何判断系统是否处于安全状态？举例说明安全序列的推导；
3. 死锁和活锁的区别？如何避免活锁？

### 模块 5：中断与系统调用

#### 核心知识点

1. 中断分类：硬中断（外中断：I/O/ 时钟）、软中断（内中断 / 异常：缺页 / 系统调用）；
2. 中断处理流程：保存上下文→中断处理→恢复上下文→返回；
3. 系统调用：用户态请求内核服务的接口（fork/exec/read），通过陷入指令触发；
4. 内核态 vs 用户态：权限、指令集、地址空间、切换方式。

#### 面试高频考点

- 中断与异常的区别；
- 系统调用与普通函数调用的区别；
- 内核态 / 用户态的切换原理。

#### 经典面试题

1. 系统调用属于中断吗？用户态如何切换到内核态？
2. 中断处理流程中，为什么要保存 / 恢复上下文？
3. 内核态和用户态的核心区别？哪些操作必须在核心态执行？

## 三、备考建议

1. **核心模块优先**：进程线程、内存管理、死锁是必背模块，需掌握 “原理 + 场景 + 实现”；
2. **手写代码 / 伪代码**：重点练生产者 - 消费者（信号量）、LRU 实现（哈希表 + 双向链表）；
3. **结合 Linux 实例**：如 inode、fork/exec 系统调用、管道通信，面试常结合 Linux 实际场景提问；
4. **对比类问题强化**：如进程 vs 线程、分页 vs 分段、自旋锁 vs 互斥锁，需总结 “维度化对比表”（如资源开销、适用场景、实现成本）。
