# Buffer Pool（缓冲池）
#### 定义
Buffer Pool 是 `InnoDB` 存储引擎的**核心内存组件**，作用是将磁盘数据缓存在内存中，**大幅减少磁盘 I/O，提升 MySQL 读写性能**

#### 原理
- **页为单位缓存**：`InnoDB` 以「**页**」(默认 16KB)为磁盘和内存交互的基本单位，查询一条记录时，会将**整个数据页**加载到 Buffer Pool，再通过页目录定位具体记录
- ([[2.索引篇#InnoDB是怎么存储/查询数据的？|查询一条记录 -> 缓存一整个数据页]])
- **读写流程**：
    - **读**：数据命中 Buffer Pool 则直接读取，未命中则从磁盘加载到 Buffer Pool 再读取
    - **写**：修改数据时，仅修改 Buffer Pool 中的页（标记为「脏页」），不立即刷盘，由后台线程定期刷回磁盘，减少随机 I/O

#### 缓存内容
- 数据页（聚簇索引 / 非聚簇索引的完整数据）
- 索引页
- undo 页（undo log 存储页）
- 插入缓存页、自适应哈希索引、锁信息等
