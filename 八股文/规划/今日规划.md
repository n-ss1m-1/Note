	- [ ] static总结
		1. 修饰局部变量
			- 生命周期：**从第一次初始化到程序结束**。
			- 作用域：仍在函数 / 块内。
			- 只初始化**一次**，多次调用函数值会保留。
		2. 修饰全局变量/函数
			- 若声明在.h文件->每个包含它的源文件拥有自己独立的该static变量
			- 作用域限制在**当前 .cpp 文件**（内部链接）。
			- 其他文件无法通过 `extern` 访问，避免命名冲突。
		3. 修饰类成员变量
			- 属于**类**，不属于任何对象，所有对象共享一份。
			- 必须在**类外初始化**。
			- 可通过 `类名::变量名`或 `对象.变量名` 访问。
		4. 修饰类成员函数
			- 属于类，不属于任何对象，没有 `this` 指针。
			- 只能访问**静态成员变量 / 静态成员函数**。
			- 不能访问普通成员变量。
			- 调用：`类名::函数()` 或 `对象.函数()`。
	- [ ] C中的struct相比C++的struct
		1. 没有访问权限控制
		2. 不能定义成员函数
		3. 声明变量需要加上struct关键字
	- [ ] C++：stuct和class的异同
		- 相同：
			1. 都用来定义自定义类型
			2. 都有：成员变量、成员函数、构造函数、析构函数
			3. 都支持继承、多态、访问控制权限
			4. 都支持static、const、友元、运算符重载
			5. 内存布局规则一致
		- 不同：
			1. 默认访问权限
			2. 默认继承方式

				2. 虚指针：相应的对象内部都隐含一个虚指针，指向所属类的虚函数表

			1. 系统管理/手动管理(申请、释放)
				- 栈：系统自动管理
				- 堆：手动管理
			2. 空间大小
				- 栈：小，固定大小，几MB
				- 堆：大，几乎受限于虚拟内存
			3. 分配效率
				- 栈：快，只需移动栈指针
				- 堆：慢，需要寻找空闲块
			4. 生长方式
				- 栈：向低地址增长(向下)
				- 堆：向高地址增长(向上)
			5. 存储内容
				- 栈：局部变量、函数参数、返回地址
				- 堆：动态分配的对象
			6. 碎片问题

				- `free` 时内存**直接归还操作系统**
				- 无碎片
