# 7 天 MySQL 面试速成学习规划（严格匹配知识点分级清单）

## 整体核心原则

1. **优先级铁律**：每天先 100% 吃透「必记的面试核心」，学有余力再看「可浅尝辄止的内容」，全程绝对不碰「可直接略过的内容」，一周周期内所有略过内容全部放弃，不浪费 1 分钟。
2. **学习逻辑**：从顶层架构→执行流程→数据存取→底层支撑→并发控制→性能优化，循序渐进，强绑定关联知识点，避免碎片化。
3. **时间分配**：每天总时长 5-7 小时，上午 2-3h 啃核心理论，下午 2-3h 做实操验证，晚上 1h 复盘 + 针对性刷题，形成闭环。
4. **达标要求**：每天所有「必记内容」必须做到「能口述结论 + 讲清底层逻辑 + 实操验证」，面试能直接输出。

## 一、架构篇

### 必记的面试核心
